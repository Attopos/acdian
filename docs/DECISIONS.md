## 2026-11-13 模块支持 readOnly

- 背景：Atlas 模块的内容由同步脚本从各项目生成，在 App 里改了也会被下次同步冲掉。
- 决定：`.acdian-modules.json` 的模块可写 `"readOnly": true`。编辑器对其中页面关闭编辑；保存、删除、改名、移入、新建文件夹、导入附件都在 AppModel 里拦下。只有为 true 时才写进 JSON，其他模块的记录不变。
- 放弃的方案：只靠同步覆盖、不改 App（能改但会丢，容易误以为保存了）。

## 2026-11-13 侧栏插入线按行订阅

- 背景：每行的插入线都用 `@ObservedObject` 观察同一个拖动状态，高亮每变一次，懒加载列表里已建过的行全部重算；在大文件夹里滚动过之后拖动明显卡顿。

## 2026-11-13 闲置标签页自动关闭

- 背景：标签页越开越多，用户希望 30 分钟没用的自动关掉。
- 决定：每个标签页记下最后在前台的时间，每分钟检查一次，后台超过 30 分钟就关闭。前台标签页和分屏页面不关。切换标签时已经保存过，所以关闭后台标签不会丢内容。时间只存在内存里，重启后从启动时重新计时。
- 放弃的方案：把时间存进偏好设置（隔天重启会一次关掉几乎所有标签页，太突然）；在 App 不在前台时暂停计时（规则更难懂）。

## 2026-11-13 链接按钮再点一次取消链接

- 背景：选中链接文字时希望 🔗 正确亮起，并能再点一次取消链接。
- 决定：🔗 按选区碰到的任一 Markdown 链接亮起（可跨多行），亮起时点击去掉选区内所有链接，只留文字并保持选中；没亮时点击照旧打开输入框。⌘K 仍用来编辑链接地址。`[[页面]]` 链接不变（按钮仍禁用）。裸网址在编辑器里本来就不显示为链接，不算。
- 放弃的方案：亮起时点击打开输入框、清空地址才取消（多一步，和加粗等按钮的开关行为不一致）。

## 2026-11-13 右键不弹系统菜单

- 背景：用户不希望在 ACdian 里右键或长按时出现 Apple 自带的菜单，所有设备都一样。
- 决定：所有 ACdian 网页（编辑器、分屏、阅读页、交互块框架）在 `contextmenu` 事件上 `preventDefault`；Mac 的 PDF 视图不返回菜单；iOS 网页视图改用 `MenuFreeWebView`，在 `buildMenu` 里去掉上下文菜单的系统项，并关掉链接预览。ACdian 自己的菜单（图片右键、侧栏）不受影响；iPad 主菜单（键盘快捷键）不动。
- 代价：系统菜单里的拼写建议、查询、翻译、服务也一并没有了；iPhone 上不能再用气泡拷贝粘贴，只能用键盘或 ACdian 自己的按钮。

## 2026-11-15 新建表格像飞书一样用网格选大小

## 2026-11-15 空标题用 CSS 显示 H1 提示

- 背景：空标题（`## ` 后没字）整行都是字号为 0 的隐藏语法，后面还跟着 H1 提示 widget，光标落在两个元素之间，WebKit 给不出光标框，输入法候选框跑到窗口左上角。
- 决定：提示改用行上的 `::after` 显示；整行只有前缀时，前缀最后一个空格保留真实字号（透明），让光标有位置。空引用行同理。代价是空标题的光标比行首右移一个空格宽（约 4pt）。

## 2026-11-15 插入菜单：去掉目录，加分割线

- 决定：Aaron 要求去掉“Contents”。只从插入菜单拿掉，已写进页面的 `[TOC]` 照常显示。分割线插入 `--- ` 单独一行，光标放到下一行；上一行有字时先补空行，否则 `---` 会把上一行变成二级标题（Setext）。

## 2026-11-15 表格删除行列用把手 + 菜单

## 2026-11-15 飞书式块拖动

- 参考：飞书文档悬停块时左侧出现 ⋮⋮，菜单可改格式、剪切复制删除、在下方添加，拖动时蓝线标出落点（据 woshipm 2022 年的拆解，可能已变）。
- 决定：块取语法树顶层节点，列表拆成顶层列表项（子项跟随）。把手放在文字左侧 52pt，夹在目录长短线（60–80pt）和标题折叠箭头（约 30pt 以内）之间。移动时带走块旁较宽的空行，落点处补空行，列表项之间保持单行；段落放进列表中间时前后都补空行，避免变成列表项的续行。落点线用 ACdian 的粉色而不是飞书的蓝色。
- 暂不做：多块拖动、横向拖动改缩进、分栏、剪切（用复制 + 删除代替）。

## 2026-11-15 光标不再乱飞

- 隐藏语法改成全高零宽：CodeMirror 按各段的框找点击位置，0 高的框在行顶被当成“上一行”，把点击拉到格式末尾。
- 格式边界处光标靠向可见文字一侧（只改 assoc，不改位置）；点列表缩进或圆点时光标移到文字开头，只对鼠标点击生效，方向键不受影响。

## 2026-11-17 空行离开后保留，--- 不再变标题

- 两行文字之间敲出的空行，光标离开时只剩一个 Markdown 分隔空行（隐藏），看起来像消失。离开时补一个换行，让它成为“留下的空行”；文末空行也照此显示，只隐藏文件最后那一行。
- 段落正下方的空行里打 `-` 或 `=` 会把段落变成 Setext 标题。这时先在上方补空行，让 `---` 自成一块成为分割线；代价是 `-1℃`、`==高亮==` 这类开头的行也会和上一段分开。

## 2026-11-17 高亮只铺底色

- 原来高亮带左右内边距（编辑器 .15em、阅读页 4px），一段字高亮后整行变宽；文字改成深粉／浅粉色，反而不如正文清楚。改成和 Notion、Obsidian 一样：不加内边距，文字用原色，底色调淡（浅色 #ffd3e6，深色粉 35%）。

## 2026-11-17 侧栏模块改成常驻图标网格

- 参考 Dia 浏览器的固定网站：模块不再是带名字的列表、进模块后也不再收成一行返回栏，而是侧栏顶部常驻的图标网格（自适应列数，侧栏默认宽度约 3 列），名字只在悬停提示里。当前模块图标提亮（浅色模式白底、粉色细边和淡粉光晕；深色模式白 18%），不用变暗，再点一次回到所有模块；“页面”标题换成当前模块名。

## 2026-11-17 侧栏调宽把手改成 AppKit 视图

## 2026-11-17 ⌘[ / ⌘] 页面后退前进

- 历史是全局的一条（像 Obsidian 的单窗格、浏览器的单标签），不按标签页分：链接点到已在别的标签页里的页面时会切标签，按标签记录的话 ⌘[ 回不到原页面。后退时页面已有标签就切过去，否则在当前标签打开；已删除的页面跳过；改名、移动时历史跟着改。

## 2026-11-17 目录刻度跟随评论栏

iPhone 只读：编辑需要拖动和连线，留给 Mac 和 iPad。窄屏把每个阶段排成一列、按宽度适配并从顶部开始，代替整张缩小到看不清；详情用底部抽屉，聚焦时把节点移到抽屉上方。「在路线图中的位置」放在页面工具栏，而不是做新的面包屑。

## 2026-11-20 路线图拖动不重绘

拖动时不再每帧改 SVG 的 transform（会重绘全部节点），而是把画布做得比视口四周各大 360pt，拖动只用 CSS translate 平移这张已画好的图（GPU 合成），松手或拖出边距时才重绘一次。缩放仍逐帧重绘。窄屏走原生滚动，不用这套。

## 2026-11-20 详情面板加宽到三分之二

宽屏下详情面板从一半加宽到三分之二：读页面内容时图和要点更舒展，左侧剩下的三分之一够看当前阶段和前置连线。窄屏抽屉不变。

## 2026-11-21 路线图手势期间整张平移缩放

拖动、触控板滚动和捏合时都只对已画好的画布做 CSS 平移和缩放（画布四周各多画 600pt），手势停 160ms 或画布露边时才重绘一次；手势期间画布不响应悬停。卡片去掉 drop-shadow，浮层去掉毛玻璃，换成实底：这两样在 WebKit 里每帧都要重算。代价是捏合时字会短暂发虚。

## 2026-11-21 路线图去掉悬停，详情面板分区

画布上不再有任何悬停效果和弹出卡片（节点、连线都不监听指针移动），看内容一律点开详情面板。面板按「要点（按来源页面分组）｜页面、关系（先学 / 学完可以继续 / 相关，带数量）、学习路径」分区，右侧每块一张浅底卡片。

## 2026-11-21 路线图改用 Canvas 绘制

SVG 仍是唯一的模型：`SvgRaster` 读 SVG 的计算样式生成绘制列表，画进比视口四周各大 320pt 的位图；手势中只对位图做 CSS 平移缩放，停下或露边才重画。
编辑和窄屏仍用 SVG，因为拖拽、连线依赖 DOM 事件。放在 `Resources/kit/`，以后其他组件也能复用。

## 2026-11-21 路线图位图改为分块并转成图片

整张缓存在大幅拖动露边时要整张重画，仍卡。改成 512pt 分块，空闲时预画周围两圈；画好的块用 toBlob 换成 <img>，因为浏览器合成大量 canvas 图层很贵、合成图片很便宜。
拖动中不画新块，露出的地方用整图缩略垫底，停下再补清晰块。

## 2026-11-21 路线图缩放期间不重画

缩放手势和按钮动画期间只缩放已有的块，语义缩放档（远 / 中 / 近）也等停下再切，因为切档要改上千个 SVG 元素并重建绘制列表。
停下时先同步画一张视口大小的过渡图，块在 DOM 外画好转成图片后再盖上去，页面里不长期保留 canvas。

## 2026-11-21 内置组件抽出公共层

以后会有很多内置表单，所以把路线图里通用的部分抽出来：网页侧 `kit/kit.js` 管通信、主题、多语言和小工具，App 侧 `ComponentBridge` 管握手和去重，Mac 和 iOS 宿主只剩 WebView 配置。
编辑器暂不迁：它是 CodeMirror 打包产物，接口多、测试重，等有需要再动。

## 2026-11-21 路线图悬停加回来

连线上的说明要靠悬停看，所以恢复节点卡片、连线说明和走廊线列表。命中仍由透明 SVG 负责；高亮不改原 SVG（改了就要重建位图），而是把被悬停的元素克隆到单独的 `#hilite` 浮层。拖动和缩放开始时立刻收起。

## 2026-11-21 路线图适配 iPad 和 iPhone

手机按最短边判断（横屏也走单列布局），因为横屏高度只有约 390pt，桌面布局放不下。iPad 竖屏详情改成底部面板，横屏面板约一半宽；Mac 仍是三分之二。
iPad 首屏不再缩到整张图（约 25%，字看不清），而是铺满第一条流程。手机上去掉成片淡入淡出动画和悬停；iPad 位图块缓存减半省内存。
