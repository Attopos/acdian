## 2026-11-13 文档进仓库，用 Atlas 汇总

- 背景：希望换 AI 工具后能从断掉的地方立即续上。

## 2026-11-13 模块支持 readOnly

- 背景：Atlas 模块的内容由同步脚本从各项目生成，在 App 里改了也会被下次同步冲掉。
- 决定：`.acdian-modules.json` 的模块可写 `"readOnly": true`。编辑器对其中页面关闭编辑；保存、删除、改名、移入、新建文件夹、导入附件都在 AppModel 里拦下。只有为 true 时才写进 JSON，其他模块的记录不变。
- 放弃的方案：只靠同步覆盖、不改 App（能改但会丢，容易误以为保存了）。

## 2026-11-13 规则只保留仓库里的一份

- 背景：`~/Developer/acdian/CLAUDE.md` 是 Atlas 之前手写的规则副本，和仓库 `AGENTS.md` 并存，读错路径时拿到旧规则；Claude Code 还会同时加载上级目录的 CLAUDE.md，两份规则会互相矛盾。
- 决定：删掉外层副本，规则只写在仓库 `AGENTS.md`，并在其中写明从外层目录开工时去哪读。
- 放弃的方案：外层留一行 `@Project/work/acdian/AGENTS.md` 引用（在仓库里开工时会被重复加载）。

## 2026-11-13 侧栏插入线按行订阅

- 背景：每行的插入线都用 `@ObservedObject` 观察同一个拖动状态，高亮每变一次，懒加载列表里已建过的行全部重算；在大文件夹里滚动过之后拖动明显卡顿。
- 决定：每行有自己的小状态对象（`SidebarRowDrop`），拖动状态改变时只清掉离开的行、设置进入的行，重绘只落在这两行上。最初用 `onReceive` 加 `@State`，放下后会漏掉清除，留下残线，已弃用。
- 放弃的方案：在侧栏顶层画一条浮动插入线（要追踪每行位置，改动大）。

## 2026-11-13 只读模块允许调整顺序

- 背景：Atlas 只读后，侧栏里连拖动排序也被拦下，用户以为拖动坏了。
- 决定：同一文件夹内的重排放行，因为它只写资料库根目录的 `.acdian-order.json`，同步脚本不会覆盖；移入、移出和跨文件夹移动仍然拦下。
- 放弃的方案：只读模块完全不能拖（看起来像 bug）。

## 2026-11-13 闲置标签页自动关闭

- 背景：标签页越开越多，用户希望 30 分钟没用的自动关掉。
- 决定：每个标签页记下最后在前台的时间，每分钟检查一次，后台超过 30 分钟就关闭。前台标签页和分屏页面不关。切换标签时已经保存过，所以关闭后台标签不会丢内容。时间只存在内存里，重启后从启动时重新计时。
- 放弃的方案：把时间存进偏好设置（隔天重启会一次关掉几乎所有标签页，太突然）；在 App 不在前台时暂停计时（规则更难懂）。

## 2026-11-13 链接按钮再点一次取消链接

- 背景：选中链接文字时希望 🔗 正确亮起，并能再点一次取消链接。
- 决定：🔗 按选区碰到的任一 Markdown 链接亮起（可跨多行），亮起时点击去掉选区内所有链接，只留文字并保持选中；没亮时点击照旧打开输入框。⌘K 仍用来编辑链接地址。`[[页面]]` 链接不变（按钮仍禁用）。裸网址在编辑器里本来就不显示为链接，不算。
- 放弃的方案：亮起时点击打开输入框、清空地址才取消（多一步，和加粗等按钮的开关行为不一致）。

## 2026-11-13 右键不弹系统菜单

- 背景：用户不希望在 ACdian 里右键或长按时出现 Apple 自带的菜单，所有设备都一样。
- 决定：所有 ACdian 网页（编辑器、分屏、阅读页、交互块框架）在 `contextmenu` 事件上 `preventDefault`；Mac 的 PDF 视图不返回菜单；iOS 网页视图改用 `MenuFreeWebView`，在 `buildMenu` 里去掉上下文菜单的系统项，并关掉链接预览。ACdian 自己的菜单（图片右键、侧栏）不受影响；iPad 主菜单（键盘快捷键）不动。
- 代价：系统菜单里的拼写建议、查询、翻译、服务也一并没有了；iPhone 上不能再用气泡拷贝粘贴，只能用键盘或 ACdian 自己的按钮。

## 2026-11-14 目录只用悬停长短线，不再推挤正文

- 背景：Aaron 希望空间够时正文尽量居中，随后明确：目录不再推挤正文，不悬停时用长短线表示层级，悬停显示详情。
- 决定：去掉停靠目录和推挤布局，所有宽度下都是正文左侧 26pt 外的一列长短线，悬停时在原处弹出圆角标题列表（短横线 + 标题，当前项粉色加粗，下级缩进）。页面内的显示/隐藏按钮去掉，用菜单和 ⇧⌘L。
- 推翻：2026-11-10 的“空间够时停靠、不够时推挤”；当时他觉得悬停长条“难受”，这次是他主动要求这种样式。
