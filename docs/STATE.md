# 状态

## 现在

Mac 和 iOS 版 1.7.2（iOS 构建号 1）。
- Mac 侧栏改成筛选式（Kombai 方案 C 的样式）：顶部常驻「筛选」框，下面是模块、类型、标签（取自标题里的每个【】；侧栏、标签页、⌘O、页面标题和路线图里【】显示成小标签，文件名不变）、修改时间四组，后三组可收起；有筛选时侧栏下半部列出结果（按修改时间），没有筛选时进入模块仍是原来的文件树，可在标题行切到「按修改时间列出」。代码在 `Sources/SidebarFacets.swift`，筛选状态和结果在 `AppModel`（`facetKinds`、`facetTags`、`facetAge`、`filteredFiles`）。
- ⌘F 是本页查找（编辑器、只读页、路线图都有）；⇧⌘F 是全库搜索（`VaultSearchView`，搜标题和正文，列出页面和命中片段，点开后在页内定位到命中处）。
- ⌘O「跳转到页面」（方案 B 的样式）：`Sources/QuickJump.swift`。标题命中按被链次数排序，每条显示「最常链到它的页 → 页面 → 它最常链到的页」，下面是正文提到的页；Tab 切换全部模块 / 当前模块，⌥↵ 在分屏打开（编辑器里 ⌘K 仍是编辑链接，所以用 ⌘O）。链接统计 `AppModel.linkFacts` 从搜索缓存里的 `[[ ]]` 算出。
- iPhone 首页（方案 A 的样式）：顶部横排模块切换，下面是当前模块的文件夹和页面，搜索框跳转全库。iPad 不受影响。
- 页面编辑器手感（2026-11-23）：空行和段落同高、离开行时版面不动、只含空格的行照常显示；左右键一次走一个看得见的字（隐藏的 ** ` [ ] 不再多占一次按键，光标不消失），上下键不跳行、能进表格；行首回车把标题/列表整块下推，退格跨过隐藏空行直接合并，代码块边缘的退格不再破坏围栏。
- 中文旁的强调（2026-11-24）：`**`、`*`、`__`、`_` 一侧贴着「」“”等标点、另一侧是汉字时也算加粗/斜体，如 `一**「本地」**的`；编辑器（lezer）和渲染（marked）共用 `Resources/cjk-emphasis.js` 的放宽规则，没有中日韩字符的地方仍按 CommonMark。
- 评论（2026-11-27）：评论高亮嵌在表格单元格 span 里面，不再把单元格拆开挤出表格；正在写的第一条评论和发出后排版完全一样（时间行、文字位置、卡片高度），只是文字和边框是黄色，发出后变回普通颜色，卡片收起回复框（Mac）。
- 知识路线图（CS 模块首页 `CS/CS 路线图.acdian`）主界面是结构图（2026-11-28）：Mac 和 iPad 上每个阶段是一张小结构图，知识点就是图里的部件（只画图标或真实 logo，写了页面的亮、待写的暗），部件之间用手绘笔触的连线接起来（实线是主流程，虚线是支撑关系），阶段之间由流程线串起来，一条流程太长时折成两行。位置和连线存在阶段的 `diagram`（`slots` 是格子坐标，`wires` 是连线，`in`/`out` 是阶段入口出口），图标名存在节点的 `glyph`（Lucide 名，或 `logo-tailscale` 这类品牌 logo）。悬停显示名称，放大到 120% 以上出现名称，点击选中并打开详情面板。iPhone 仍是单列文字卡片。
